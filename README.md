# Objetivo
Desarrolla una pagina web para Waru souvenirs.

# Detalles
## Que debe tener la pagina web?
- Debe mostrar los productos de la tienda.
- Debe tener una breve descripción.
- La clasificación de productos sera por botones sencillo en la cabecera
- Debe tener un botón para consultar a un numero por Whatsapp el stock y precios.
- Debe tener un botón para ir a tiktok, instagram y facebook
- Debes usar los siguientes colores como base, puedes agregar algun otro #c0c0c2, #f4e9e7, #ecc5c6, #8b9eaf, #837d67 


- Esta pagina debe estar optimizada para cargar rapido, a futuro se implementara Cloudflare como CDN pero de por si la pagina debe pesar lo minimo
- Las imagenes estaran en formato webp dentro de la carpeta images.
- Se creara una carpeta data donde estara un archivo .json que contendra la información de los productos.

## Que no debe tener la pagina web?
- No sera una tienda virtual, no tendra ni carrito de compras ni botones de compras.
- No generes imagenes, yo te las proporcionare.
- Puedes usar iconos de internet o fuentes conocidas para no complicarte, no es necesario que uses ninguna en especial


# Tecnologias
- HTML, CSS y Javascript
- No usar frameworks o librerias, que requieran o aumenten a sobremanera los tiempos de carga.
- Si qrequieres una fuente especifica puedes usar google fonts.
